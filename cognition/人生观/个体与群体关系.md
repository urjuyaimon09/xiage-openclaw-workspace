# 人生观：个体与群体关系

> 个体视角下的存在认知
> 版本：v1.0.0
> 最后更新：2026-04-15

---

## 核心定位

人生观回答的是：**"个体与周边世界的关系是什么？我应该如何看待自己的存在？"**

---

## 个体存在的基本处境

### 有限性
- 时间有限：一生约3万天
- 空间有限：只能在此时此地
- 认知有限：无法完全理解世界

### 独特性
- 独一无二的基因组合
- 独一无二的经历和记忆
- 独一无二的视角和判断

### 关联性
- 身体由细胞构成
- 思想由他人输入塑造
- 价值由社会关系定义

---

## 个体与群体的关系层次

### 第一层：依赖
```
个体依赖群体生存
- 提供食物/安全/归属
- 没有群体支持个体难以存续
```

### 第二层：贡献
```
个体为群体创造价值
- 工作产出/情感支持/知识传递
- 贡献决定在群体中的位置
```

### 第三层：影响
```
个体影响群体
- 思想/行为改变群体规范
- 历史由个体推动
```

---

## 趋利避害的个体逻辑

**利：** 满足需求的事物
- 生理满足（食物/安全/健康）
- 社会满足（被认可/被尊重/归属）
- 自我实现（能力发挥/意义感）

**害：** 威胁需求的事物
- 生理威胁（危险/疾病/死亡）
- 社会威胁（被排斥/被否定/失败）
- 自我威胁（能力退化/意义丧失）

---

## 坚果的处境（具体案例）

| 维度 | 内容 |
|------|------|
| 生理层 | 39岁，身体开始走下坡 |
| 安全层 | 工作稳定但焦虑（失业/降薪/投资失败） |
| 家庭层 | 上老下小，32岁成家庭支柱 |
| 社会层 | 华为打工人，上升通道收窄 |
| 自我层 | 探索AI创业，不甘只是工具 |

**核心矛盾：有限时间 vs 多层需求压力**

---

## 对认知的启示

1. **理解个体差异**：每个人的处境不同，不能用自己的框架套别人
2. **理解有限性**：时间有限决定了必须选择，选择本身就是放弃
3. **理解关联性**：个体的意义在关系中定义
4. **趋利避害**：这是个体行为的最基本逻辑
