# 价值观：需求与利益驱动

> 判断框架 - 什么是对的、好的、值得的
> 版本：v1.0.0
> 最后更新：2026-04-15

---

## 核心定位

价值观回答的是：**"什么是好的、正确的、值得追求的？"**

它的本质是：**需求驱动的判断框架**

---

## 需求的层次结构（参考马斯洛）

| 层级 | 需求 | 本质 |
|------|------|------|
| L1 | 生理需求 | 身体存续 |
| L2 | 安全需求 | 稳定可控 |
| L3 | 社交需求 | 被接纳认可 |
| L4 | 尊重需求 | 被尊重认可 |
| L5 | 自我实现 | 能力释放/意义实现 |

**优先级铁则：低层未满足时，高层需求弱**

---

## 利益驱动机制

### 个体利益
```
需求 → 利益判断 → 行动 → 结果 → 反馈
```

### 群体利益
```
个体利益交叉点 → 共同利益
                    ↓
            博弈 → 均衡 → 规范
```

### 利益冲突
- 短期利益 vs 长期利益
- 个人利益 vs 群体利益
- 显性利益 vs 隐性利益

---

## 判断框架

### 一个行动是否"值得"？

```
价值 = 收益 / 投入

收益 = 直接收益 + 间接收益 + 长期收益
投入 = 时间 + 精力 + 机会成本 + 风险
```

### 利益最大化的约束

| 约束 | 内容 |
|------|------|
| 物理约束 | 能量守恒、因果律 |
| 社会约束 | 法律、道德、群体规范 |
| 自我约束 | 三观、底线、承诺 |

---

## 价值观的形成与改变

### 形成
- 基因本能（趋利避害）
- 成长经历（经验教训）
- 社会学习（文化传承）
- 理性反思（主动构建）

### 改变触发
- 重大事件冲击
- 认知升级（发现新规律）
- 需求变化（年龄/处境）
- 利益重新分配

---

## 对认知的启示

1. **价值观是利益的映射**：理解一个人的价值观，就能预测他的行为
2. **利益是多层次的**：不能只看物质利益，社交/尊重/意义同样重要
3. **利益是动态的**：随处境变化，价值观也会调整
4. **冲突是常态**：不同价值观的人之间，冲突不可避免
