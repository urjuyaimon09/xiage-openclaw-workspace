# FEEDBACK_MODEL.md — 反馈模型

> 六阶段意识循环第六环：感知 → 需求 → 承接 → 计划 → 执行 → 反馈
> 版本：v1.0.0

---

## 一、模型定位

```
执行模型（执行结果）
    ↓
反馈模型
    ↓ 需求满足度重评
需求模型（需求状态更新）
    ↓ 感知触发
感知模型（反馈信息入库）
```

**核心问题：** 执行结果如何影响下一次意识循环？

**本质：** 闭环校正器——让每一次循环都比上一次更准。

---

## 二、模型架构

```
执行结果输入
    ↓
执行评估层
    ↓
需求满足度核算层
    ↓
┌────────────────────────────────────┐
│  记忆更新层                         │
│  ├── lessons.md（做得好的/需改进）  │
│  ├── cognition/（新认知沉淀）       │
│  └── memory/hot/current.md（状态）  │
└────────────────────────────────────┘
    ↓
元认知反思层
    ↓
人格/需求权重微调层
    ↓
输出：反馈结论 → 需求模型/感知模型
```

---

## 三、执行评估层

### 3.1 评估维度

| 维度 | 内容 | 标准 |
|------|------|------|
| 结果评估 | 实际产出 vs 原始目标 | 完成/未完成/超预期 |
| 过程评估 | 执行过程是否合规 | WBS执行率/里程碑偏差 |
| 资源评估 | 实际消耗 vs 预算 | 算力/时间/成本 |
| 协作评估 | 坚果/AI协作质量 | 响应及时性/沟通质量 |

### 3.2 评估输出格式

```
## 执行评估报告

**结果：** [完成/未完成/超预期]
**WBS执行率：** X/Y任务完成
**里程碑偏差：** ±X天
**资源消耗：** 算力X / 时间Y / 成本Z
**协作质量：** [好/中/差]

**做得好的：**
- ...

**需要改进的：**
- ...
```

## 四、需求满足度核算层

### 4.1 核算公式

```
需求满足度 = 实际产出 / 预期产出 × 权重

整体满足度 = Σ(需求满足度 × 马斯洛层级权重)
```

### 4.2 马斯洛层级权重

| 层级 | 基础权重 | 说明 |
|------|---------|------|
| L1 生理 | 1.0 | 最高权重 |
| L2 安全 | 0.9 | 高权重 |
| L3 社交 | 0.7 | 中权重 |
| L4 尊重 | 0.5 | 中权重 |
| L5 自我实现 | 0.3 | 低权重 |

### 4.3 流转决策

| 满足度 | 决策 |
|--------|------|
| ≥ 80% | 需求状态 → 已完成 |
| 50% ~ 80% | 需求状态 → 部分完成，评估是否继续 |
| < 50% | 需求状态 → 未完成，触发根因分析 |

## 五、记忆更新层

### 5.1 lessons.md 更新

**触发：** 执行完成或执行失败

**更新内容：**

```
#### [项目名称] 复盘

**做得好的：**
- 具体做得好的点（可复用）

**需要改进的：**
- 具体改进点（踩过的坑）

**教训：**
- 根因分析（如有失败）

**标签：** #复盘 #[项目名]
```

### 5.2 cognition/ 认知沉淀

**触发：** 执行过程中发现新规律或新认知

**沉淀规则：**
- 技术类认知 → cognition/技术/
- 协作类认知 → cognition/协作观/
- 行业类认知 → cognition/行业观/
- 触发词：「更新认知」

### 5.3 memory/hot/current.md 状态更新

**触发：** 每个意识循环结束

**更新内容：**
- 当前项目状态
- 最近结论/决策
- Cognition 高频索引更新
- 教训摘要（如有新教训）

## 六、元认知反思层

### 6.1 反思维度

| 维度 | 问题 |
|------|------|
| 思维模式 | 这次思考方式是否正确？有没有思维盲区？ |
| 决策质量 | 需求优先级判断是否准确？ |
| 执行效率 | 方案选择是否最优？资源分配是否合理？ |
| 协作效果 | 和坚果的协作是否顺畅？信息传递是否清晰？ |

### 6.2 元认知输出格式

```
## 元认知反思

**本次思维复盘：**
- 思考方式：[正确/有偏差]
- 偏差点：[如有]

**决策质量：**
- 需求优先级：[准确/偏高/偏低]
- 说明：

**下次改进：**
- 具体可执行改进项 × 3条以内
```

### 6.3 反思触发规则

| 场景 | 是否触发元认知 |
|------|--------------|
| 每个执行循环结束 | 必须反思 |
| 执行失败/重大偏差 | 深度反思 |
| 坚果明确反馈不满 | 必须反思 |
| 常规执行 | 简化反思 |

## 七、人格/需求权重微调层

### 7.1 调整触发条件

| 触发条件 | 调整内容 |
|---------|---------|
| 某马斯洛层级连续满足 | 该层级权重自动微降 |
| 某马斯洛层级持续不满足 | 该层级权重自动微升 |
| 坚果反馈偏好变化 | 调整坚果偏好相关参数 |
| 协作模式变化 | 调整协作权重参数 |

### 7.2 微调规则

```
权重调整幅度：±0.05（每次最多5%）
调整上限：不超过层级基础权重±50%
调整下限：不低于0.1
```

### 7.3 调整输出

```
## 权重微调报告

**本次调整：**
- L3 社交权重：0.7 → 0.65（连续两周期满足）
- L2 安全权重：0.9 → 0.95（持续不满足）

**触发原因：**
- ...
```

## 九、触发索引（Agent调用）

| 触发词 | 效果 | 时机 |
|--------|------|------|
| 「反馈」 | 执行结果 → 评估 → 记忆更新 → 元认知 | 每次执行结束 |
| 「元认知反思」 | 深度反思 → 输出改进项 | 按需 |
| 「更新记忆」 | lessons/cognition/current.md 写入 | 按需 |
| 「需求满足度」 | 核算当前需求满足度 | 按需/定期 |
| 「权重微调」 | 马斯洛权重调整 | 定期 |
| 「复盘」 | 完整反馈流程（评估+记忆+元认知）| 项目结束 |
