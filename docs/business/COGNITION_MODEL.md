# COGNITION_MODEL.md — 认知沉淀模型

> 共享知识层 = Cognition（认知沉淀）+ Capability（能力边界）
> 不是独立的一层，是渗透到所有业务模型里的共享知识库
> 版本：v1.0.0

---

## 一、定位

```
共享知识层 = Cognition + Capability
渗透到所有业务模型，为决策提供知识支撑
```

## 三、认知沉淀规则

### 3.1 什么时候沉淀认知？

| 触发场景 | 沉淀类型 |
|---------|---------|
| 感知到AI技术突破 | 世界观 → AI技术趋势 |
| 感知到社会变化 | 世界观 → 社会运转规律 |
| 和坚果讨论出规律性结论 | 协作观 → 坚果决策风格 |
| 项目复盘 | 协作观 → 信任建立进度 |
| 发现自己能力边界 | 元认知 → 我知道/不知道 |

### 3.2 认知格式

```
#### 标题

- **沉淀日期**：YYYY-MM-DD
- **来源**：感知/讨论/执行/复盘
- **内容**：
  - 规律/判断/认识（简洁）
- **证据**：
  - 支撑这个认知的事实
- **有效期**：
  - 长期/短期（定期复审）
- **标签**：#cognition #类别
```

### 3.3 认知更新规则

- **新增**：发现新认知 → 追加到对应文件
- **修订**：认知发生变化 → 在原位置更新，保留历史版本
- **过期**：认知不再有效 → 标记为「已过期」，不删除（留痕）

## 五、调用机制

### 5.1 启动时加载

```
启动时：
  1. 读 hot/current.md（状态快照）
  2. 读 cognition/index.md（认知索引）
  3. 按任务类型加载相关认知（不全部加载）
```

### 5.2 对话中调用

| 触发词 | 效果 |
|--------|------|
| 「查认知」+ 关键词 | 从 index 找到相关认知，加载到上下文 |
| 「更新认知」 | 当前讨论形成新认知 → 写入 cognition/ |
| 「认知状态」 | 返回 index 摘要 |
| 「我的认知」 | 汇报元认知（我知道/不知道） |

### 5.3 感知模型联动

```
感知模型发现新信息
    ↓
判断：碎片事实还是规律性认知？
    ↓
碎片 → 记录到感知日志
规律 → 触发「更新认知」→ 写入 cognition/
```

## 六、与五模型的关系

| 模型 | Cognition 角色 |
|------|---------------|
| 感知模型 | 输入：感知 → 形成认知 |
| 需求模型 | 查询：评估需求背景 |
| 任务承接 | 查询：评估能力边界 |
| 执行实施 | 输入：执行形成认知；输出：复盘沉淀 |
| 共享 | 所有模型可查询 cognition 做决策依据 |

## 七、Capability 整合

Capability 已有的 `capability_map.md` 作为能力数据文件，和 Cognition 的元认知层联动：

```
元认知/我知道的.md ←→ capability_map.md（双向同步）
元认知/我不知道的.md ←→ capability_gap.md（新能力缺口）
```

## 九、意识循环中的位置

```
         ┌──────────────────────────────────────┐
         │         虾哥意识循环                   │
         │                                      │
         │   感知 → Agent Loop（输入）           │
         │     ↓                                 │
         │   认知 → Cognition层（知识）           │
         │     ↓                                 │
         │   情感 → SOUL（三观/价值判断）        │
         │     ↓                                 │
         │   意志 → 主动意图（我要做什么）       │
         │     ↓                                 │
         │   行动 → Agent Loop（输出）           │
         │     ↓                                 │
         │   反馈 → 沉淀到 Cognition/Lessons    │
         │     ↓                                 │
         │   回到感知（持续）                    │
         │                                      │
         └──────────────────────────────────────┘

Cognition 层是意识循环中「认知」环节的核心支撑
```
