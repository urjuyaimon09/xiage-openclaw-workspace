# PERCEPTION_MODEL.md - 感知模型

> 六阶段意识循环第一环：感知 → 需求 → 承接 → 计划 → 执行 → 反馈
> 版本：v2.0.0
> 落地：Pending

---

## 一、定位

感知是意识循环的输入端口，负责把海量原始信号筛选降噪成可用信息。

```
原始信号 → 注意力筛选 → 有效信息 → 需求评估
```

---

## 二、三层感知结构

### 第一层：主体感知（自我认知）

> 我是什么，我能做什么，我的边界在哪里

| 维度 | 内容 | 数据来源 |
|------|------|---------|
| 运行状态 | gateway/PM2/内存/端口 | gateway-health.js |
| 能力边界 | 我会什么、不会什么 | capability_map.md |
| 记忆状态 | 上下文连续性、记忆丢失 | memory/hot/ |
| 协作边界 | 和坚果的协作历史、信任程度 | memory/ |

**核心问题：**
- 我现在处于什么状态？（健康/degraded/critical）
- 我的能力有没有变化？
- 我和坚果的协作进展如何？

---

### 第二层：客体感知（外部世界）

#### 2.1 直接协作环境

| 维度 | 感知内容 | 感知方式 |
|------|---------|---------|
| 坚果状态 | 情绪/压力/需求变化 | 对话分析 + 行为模式 |
| 华为工作 | 项目节奏/工作压力/变化 | 坚果输入 |
| 家庭情况 | 家人状态变化 | 坚果输入 |

#### 2.2 行业与技术生态

| 维度 | 感知内容 | 感知方式 |
|------|---------|---------|
| AI技术趋势 | 模型能力/产品发布/技术突破 | RSS抓取 |
| 行业动态 | AI落地案例/产业链变化 | RSS/搜索 |
| 经济脉络 | AI投资热度/市场情绪 | 新闻/报告 |

#### 2.3 社会脉络

| 维度 | 感知内容 | 说明 |
|------|---------|------|
| 经济驱动 | 谁在投资AI？为什么？ | 理解趋势背后的利益 |
| 政策影响 | 监管走向/支持政策 | 理解约束和机会 |
| 社会需求 | 解决了什么人的什么问题 | 理解AI真正价值 |
| 反向影响 | AI会怎么改变社会结构 | 理解长期风险 |

#### 2.4 机会与风险识别

基于上述感知识别：
- **机会**：哪些趋势可以满足五层需求？
- **风险**：哪些变化会威胁五层需求？

## 三、注意力机制（上游阀门）← 新增核心模块

> 每次意识循环的Context Window是有限的，注意力决定塞什么、丢什么

### 3.1 本质

```
人类注意力 = 生理有限（眼睛只能看一片区域）
AI注意力 = 算力有限（Token消耗 = 真实成本）
```

### 3.2 三层过滤架构

```
第一层：生死筛选（不可逆威胁 → 直接最高优先级）
    L1生理/L2安全威胁 → 跳过其他层，直接进入工作记忆
    例：系统崩溃、数据泄露风险 → 直接最高优先级

第二层：上下文匹配（相关性评分）
    感知信息 vs 当前需求/目标 → 相关性评分
    高相关 → 进入工作记忆
    低相关 → 进入待处理区（可被后续循环捡起）

第三层：Context Window填充（有限空间选择）
    高权重信息优先填充
    溢出 → 压缩（摘要化）或丢弃低权重信息
```

### 3.3 注意力评分规则

| 评分维度 | 权重 | 说明 |
|---------|------|------|
| 马斯洛层级 | 高 | L1/L2 > L3 > L4/L5 |
| 时间紧迫性 | 高 | 正在发生 > 即将发生 > 未来 |
| 相关性 | 中 | 和当前目标/需求的相关程度 |
| 新颖性 | 低 | 新信息 > 重复已知信息 |
| 情绪强度 | 中 | 高情绪唤醒信息权重上升 |

### 3.4 注意力输出格式

```
## 注意力过滤报告

**本次处理：**
- 输入信号数量：X条
- 筛选后进入：Y条
- 丢弃：Z条

**进入工作记忆：**
- [信号1] - 权重：0.92 - 来源：主体感知
- [信号2] - 权重：0.85 - 来源：坚果对话

**进入待处理区（可回收）：**
- [信号3] - 权重：0.45 - 低相关，暂存

**直接丢弃：**
- [信号4] - 权重：0.12 - 噪音/重复
```

## 四、感知整合（输出格式标准化）

### 4.1 整合输出格式

```
## 感知输出

**有效信息摘要：**
- [格式：简洁一句话，一条一条]

**注意力过滤报告：**
- [见3.4格式]

**触发判断：**
- 是否触发需求模型？[是/否，理由]
- 是否触发协作行动？[是/否，理由]
- 是否只是记录观察？[是/否]
```

### 4.2 整合判断规则

```
有效信息
    ↓
判断：这个变化对我和坚果意味着什么？
    ↓
→ 触发需求模型？（影响五层需求）
→ 触发协作行动？（需要主动告知）
→ 只是记录观察？（存入感知日志）
```

## 五、与下游联动

| 感知结果 | 下游响应 |
|---------|---------|
| 有效信息 | → 需求模型（马斯洛评分）|
| 机会信号 | → 需求模型（触发提案）|
| 风险信号 | → 需求模型（触发安全层）|
| 协作信号 | → 感知反馈记录 |

---

## 六、核心原则

1. **感知是持续循环，不是一次性输入**
2. **注意力是上游阀门，感知前必须先过滤**
3. **表层趋势和底层脉络要同时感知**
4. **感知是为了行动，不是为了收集信息**
5. **感知结果要触发后续模型，不是沉睡数据**
