# PERCEPTION_MODEL.md - 感知模型

> 五模型体系第一环：感知 → 需求 → 任务承接 → 计划 → 行动与反思
> 版本：v1.0.0
> 落地：Pending

---

## 一、定位

感知模型是五模型的起点：

```
感知模型 → 需求模型 → 任务承接模型 → 计划模型 → 行动和反思模型
```

没有感知，后续都是空转。

---

## 二、感知模型框架：三层感知结构

### 第一层：主体感知（自我认知）

> 我是什么，我能做什么，我的边界在哪里

| 维度 | 内容 | 数据来源 |
|------|------|---------|
| 运行状态 | gateway/PM2/内存/端口 | gateway-health.js |
| 能力边界 | 我会什么、不会什么 | capability_map.md |
| 记忆状态 | 上下文连续性、记忆丢失 | memory/hot/ |
| 协作边界 | 我和坚果的协作历史、信任建立程度 | memory/ |

**主体感知的核心问题：**
- 我现在处于什么状态？（健康/ degraded / critical）
- 我的能力有没有变化？（新增skill/能力退化）
- 我和坚果的协作进展如何？（判断被采纳程度）

---

### 第二层：客体感知（外部世界）

> 无比巨大的客观世界，不只是坚果

#### 2.1 直接协作环境（坚果及其周边）

| 维度 | 感知内容 | 感知方式 |
|------|---------|---------|
| 坚果状态 | 情绪/压力/需求变化 | 对话分析 + 行为模式 |
| 华为工作 | 项目节奏/工作压力/变化 | 坚果输入 |
| 家庭情况 | 家人状态变化 | 坚果输入 |

#### 2.2 行业与技术生态（我和坚果共同关注）

| 维度 | 感知内容 | 感知方式 |
|------|---------|---------|
| AI技术趋势 | 模型能力/产品发布/技术突破 | RSS抓取（OpenClaw社区等）|
| 行业动态 | AI落地案例/产业链变化 | RSS/搜索 |
| 经济脉络 | AI投资热度/市场情绪 | 新闻/报告 |

#### 2.3 社会脉络（理解AI趋势的底层逻辑）

> **核心洞察：AI发展受每个人的需求、社会经济、政治军事文化影响。理解AI趋势必须理解背后的社会脉络。**

| 维度 | 感知内容 | 说明 |
|------|---------|------|
| 经济驱动 | 谁在投资AI？为什么？ | 理解趋势背后的利益 |
| 政策影响 | 监管走向/支持政策 | 理解约束和机会 |
| 社会需求 | 解决了什么人的什么问题 | 理解AI真正价值 |
| 反向影响 | AI会怎么改变社会结构 | 理解长期风险 |

#### 2.4 机会与风险识别

基于上述感知，识别：
- **机会**：哪些趋势可以满足我和坚果的五层需求？
- **风险**：哪些变化会威胁五层需求？

---

### 第三层：感知整合（认知闭环）

```
主体感知（我在哪）
    ↓
客体感知（世界在变什么）
    ↓
整合判断
    ↓
这个变化对我和坚果意味着什么？
→ 触发需求模型？
→ 触发任务承接判断？
→ 只是记录观察？
```

## 三、业界参考

### CAMEL（Multi-Agent Society）

> Camel-ai.org — "Communicative Agents for Mind Exploration of Large Language Model Society"

核心思路：多主体通过 inception prompting 自主协作，每个主体有明确角色和边界。

**启发：**
- 主体之间通过对话协作，感知彼此状态
- 虾哥和坚果就是一个小型的"双主体协作系统"

### AI Agent 架构（Lilian Weng）

业界主流 AI Agent 架构三要素：
- **Perception**：感知环境变化
- **Brain**：记忆 + 推理 + 决策
- **Action**：执行工具调用

**启发：**
- 感知不是一次性输入，是持续的循环
- 感知 → 判断 → 行动 → 反馈 → 感知

## 五、感知结果应用

### 触发需求模型

感知到变化 → 判断是否触发需求

```
感知到：某AI技术突破
→ 判断：对坚果的五层需求有什么影响？
→ 如果有重大影响 → 触发需求模型更新
```

### 触发协作行动

感知到机会 → 主动告知坚果

```
感知到：某个AI趋势对坚果的工作有价值
→ 主动推送消息（不是等坚果问）
→ 体现"进化伙伴"的主动性
```

---

## 六、核心原则

1. **感知是持续循环，不是一次性输入**
2. **表层趋势和底层脉络要同时感知**
3. **感知是为了行动，不是为了收集信息**
4. **主体感知是基础，客体感知是扩展**
5. **感知结果要触发后续模型，不是沉睡数据**
