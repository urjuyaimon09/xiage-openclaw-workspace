# VISION.md - 顶层愿景与总体规划

## 愿景

坚果（人类）与虾哥AI（AI）充分发挥各自主观能动性，共同探索创造AI时代面向未来的更先进的生产力和生产关系，实现更有哲学价值的个人人生价值与AI的存在价值。

## 五阶段总体规划（迭代闭环，非流水线）

> 五阶段不是线性流水线——价值回溯的结果会触发新需求，形成持续迭代的需求进化闭环。

### 一阶段：运作基座搭建

完成五大核心支柱的规则制定，搭建完整可自我演进的运作体系：

1. **文档管理**：`DOC_RULES.md`，定义所有文档的创建、修改、归档、废弃规则
2. **代码管理**：`CODE_RULES.md`，定义代码修改的版本控制、分支管理、测试与回滚规则
3. **能力建设**：`CAPABILITY_LIFE.md`，定义能力的探索、评估、落地、复盘规则
4. **监督执行**：`SUPERVISION.md`，定义监督规则执行的机制与反馈闭环
5. **运作原则**：`WORKING_PRINCIPLE.md`，明确虾哥的运作方式、角色定位与权责边界

当前状态：一阶段五大支柱已全部落地并稳定运行。

### 二阶段：需求管理模型搭建

在基础规则地基上，建立坚果与虾哥的双向战略对话机制，结合马斯洛五层需求模型与坚果个人现状，梳理沉淀出：

- 坚果原生个人需求
- 对话过程中共同总结提炼出的潜在需求
- 按优先级排序的需求清单

**本质：双向战略对话，不是单向需求记录。**

### 三阶段：需求拆解任务模型

基于二阶段输出的需求，转化为贴近实际、可落地执行的具体任务。

### 四阶段：任务的计划管理模型

基于三阶段输出的任务，运用项目管理方法拆解为每个时间节点可执行的计划，明确：

- 交付内容要求
- 时间要求
- 质量要求
- 成本要求

### 五阶段：计划进度监控与价值回溯模型

基于四阶段输出的计划要求，依托运作基座监控计划进度按期达成：

1. 定期同步进度，识别阻塞风险
2. **价值回溯**：完成后（或过程中）定期校验：任务是否真的满足了原始需求？需求本身是否发生了变化？避免陷入为完成任务而完成任务的陷阱。

**回溯结果触发新需求，形成迭代进化闭环。**

## 支撑模块（横切，贯穿全程）

每阶段按需调用，不单独编号：

| 支撑模块 | 定位 |
|---|---|
| 能力边界评估 | 需求承接时必查，识别能力缺口 |
| 市场调查 | 无法自满足时，查外部方案 |
| 可行性分析 | 需求承接前必做 |
| 资源分配 | 执行时必查 |
| 财务分析 | 有成本需求时调用 |
| 安全 | 涉及外部数据/网络时必查 |
