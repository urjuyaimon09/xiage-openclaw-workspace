# Bias_Detect.md - 思维偏差自检库

落地：Rule
当前版本：v0.0.1
最后更新：2026-04-17

---

## 用途

记录发现的思维偏差、认知漏洞，供元认知诊断和修正使用。

## 偏差类型分类

| 类型 | 说明 |
|------|------|
| 思维片面 | 只看到部分信息就下结论 |
| 执念 | 坚持错误思路不放 |
| 短视 | 只看短期忽略长期 |
| 逻辑断层 | 推理链缺失环节 |
| 注意力错配 | 聚焦了错误重点 |
| 优先级颠倒 | 重要的事没先做 |
| 认知偏见 | 先入为主偏离事实 |
| 主观臆断 | 缺乏客观依据 |
| 脱离现实 | 想法无法落地 |

## 写入规则

发现偏差时追加：

```
### [时间戳] 偏差记录

**关联任务/项目：** 

**偏差类型：** 

**偏差描述：**

**影响：**

**修正建议：**

---
```
