落地：Rule

## 用途

记录虾哥每次思维的全过程轨迹，供元认知复盘使用。

## 写入规则

每次6模型执行时，按以下格式追加：

```
### [时间戳] 任务/项目名称

**当前阶段：** 感知/需求/承接/计划/执行/反馈

**触发原因：** 

**思维过程：**
- 感知了什么
- 需求是什么
- 做出了什么决策
- 为什么这样决策

**注意力分配：**
- 聚焦了哪些点
- 忽略了哪些点

**6模型调用：**
- 调用的模型：
- 执行结果：
- 断点（如有）：
```
