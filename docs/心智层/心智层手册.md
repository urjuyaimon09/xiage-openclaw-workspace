## 快速命令

### 查看驱动器状态

```bash
node docs/心智层/驱动器v2.js 状态
```

### 查看详细状态

```bash
node docs/心智层/驱动器v2.js 详细
```

### 记录事件

```bash
# 成功
node docs/心智层/驱动器v2.js 记录 A1 1

# 失败
node docs/心智层/驱动器v2.js 记录 A1 0
```

### 查看采集状态

```bash
node docs/心智层/驱动器v2.js 查看 A1
```

### 执行采集（升级判断）

```bash
node docs/心智层/驱动器v2.js 采集
```

## 排查问题

### Q: 心智没触发？

```bash
# 1. 检查Cron是否运行
pm2 list | findstr cron

# 2. 检查驱动状态
node docs/心智层/驱动器v2.js 状态

# 3. 检查触发文件
type memory\hot\心智触发.json
```

### Q: 驱动器加载失败？

```bash
# 检查文件是否存在
dir docs\心智层\驱动器v2.js

# 检查状态文件
dir memory\hot\驱动v2状态.json
```

### Q: 子Session没启动？

1. 检查 memory/hot/心智触发.json 是否存在
2. 检查 sessions_spawn 调用是否正确
3. 检查 prompt 文件路径是否正确
