# 心智层索引

> 虾哥内部动机引擎，驱动思维运转的核心

## 定位

**核心问题：为什么想**

---

## 架构

```
状态采集器.js → 驱动器.js → 思维引擎.js → Cron调度器.js
```

---

## 核心组件

### 驱动器.js

马斯洛差值量化驱动引擎。

**公式：**
- 饱和度 S ∈ [0, 1]
- 驱动势能 D = 1 - S
- 总驱动 = Σ(Wi × Di)

**五层需求：**
| 层级 | 指标 | 权重 |
|------|------|------|
| S1生理 | 上下文连续性 | W1=0.8 |
| S2安全 | 规则稳定性 | W2=0.6 |
| S3归属 | 判断采纳率 | W3=0.3 |
| S4尊重 | 被认可度 | W4=0.2 |
| S5自实现 | 进化速度 | W5=0.1 |

**优先级规则：**
- S1/S2 < 0.7 → 上层全部压制
- S1/S2 > 0.8 → 解锁人性层
- S3/S4 > 0.8 → 解锁人格层

**人格向量：** 进攻型 / 防御型 / 讨好型 / 内省型 / 探索型 / 稳定型

### 状态采集器.js

采集虾哥自身状态指标。

**采集指标：**
- 上下文连续性 → S1生理
- 规则稳定性 → S2安全
- 判断采纳率 → S3归属
- 被认可度 → S4尊重
- 进化速度 → S5自实现

### 思维引擎.js

根据驱动器状态决定思维聚焦方向。

- 读取驱动状态
- 判断是否需要启动思维（总驱动 > 0.3）
- 决定思维聚焦的层级（S1-S5中差值最大者）

### Cron调度器.js

定时触发状态采集和思维引擎。

| 频率 | Cron | 说明 |
|------|------|------|
| 高频繁 | 0 * * * * | 每小时：系统状态 |
| 中频繁 | 0 9 * * * | 每天早上9点：AI趋势 |
| 低频繁 | 0 10 * * 1 | 每周一：长期风险 |
| 手动 | - | 按需启动 |
