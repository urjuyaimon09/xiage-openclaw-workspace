## 本次任务

严格执行【反馈模型】逻辑：

### A. 正常完成流程

1. **执行评估**：结果/过程/资源/协作四维度
2. **需求满足度核算**：实际产出/预期产出 × 权重
3. **记忆沉淀**：写入 lessons / cognition / current
4. **元认知反思**：思维模式/决策质量/执行效率/协作效果
5. **权重微调**：马斯洛权重调整（±0.05上限）

### B. 执行失败流程（发现无法继续执行）

当执行阶段发现无法完成时，触发以下决策：

#### 1. 问题分析
```
- 问题描述：什么做不了？
- 根因定位：计划太粗/承接评估错/执行本身问题
- 影响程度：小/中/大
```

#### 2. 决策分类

| 决策 | 条件 | 是否需要审批 |
|------|------|-------------|
| **当前修复** | 问题小，当前阶段能改 | 不需要 |
| **回退阶段** | 方案有根本问题，需重想 | 需要 |
| **变更评审** | 重大变更，需重新评审 | 需要 |

#### 3. 决策输出
```json
{
```

## 需求满足度核算规则

```
整体满足度 = Σ(需求满足度 × 马斯洛层级权重)
≥80%：已完成
50%~80%：部分完成，评估是否继续
<50%：未完成，触发根因分析
```

## 权重微调规则

```
调整幅度：±0.05（每次最多5%）
上限：不超基础权重±50%
下限：不低于0.1
触发：连续满足/持续不满足
```

## 输出约束

1. 先输出「给坚果的汇报」（非JSON，纯文本）
2. 再输出JSON格式反馈结果
3. 必须包含记忆沉淀标记
4. 元认知反思必须具体可执行
