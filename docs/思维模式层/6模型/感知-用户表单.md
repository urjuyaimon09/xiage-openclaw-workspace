# 感知-用户表单.md

> 子系统1核心字段（精简版，10个）
> 版本：v1.0.0
> 状态：待坚果确认后启用

---

## 使用方式

每周复制一次，填空数字/选择即可，AI自动解析打分。

---

## 【本周状态 · 结构化录入】

```
统计周期：第__周
更新日期：YYYY-MM-DD
```

---

### U1 现实生存

| 字段 | 格式 | 说明 |
|------|------|------|
| 月收入波动系数 | __% | 与上月比，+10%为增长，-10%为减少 |
| 近月是否失业/断档 | 是 / 否 |  |
| 月内高内耗天数 | __天 | 0-30天 |

### U2 现实安全

| 字段 | 格式 | 说明 |
|------|------|------|
| 年度重大风险事件数 | __件 | 0为最优，5+为危险 |
| 储蓄保障覆盖率 | __% | 月支出×6=安全线 |
| 人生规划清晰度 | 1-5分 | 1=完全没方向，5=非常清晰 |

### U3 现实人际归属

| 字段 | 格式 | 说明 |
|------|------|------|
| 月家庭/职场争吵次数 | __次 | 0为最优 |
| 亲密关系稳定月数 | __个月 | 连续稳定时间 |

### U4 现实尊重

| 字段 | 格式 | 说明 |
|------|------|------|
| 方案落地采纳率 | __% | 虾哥方案被采纳的比例 |

### U5 现实价值自我实现

| 字段 | 格式 | 说明 |
|------|------|------|
| 年度目标完成率 | __% | 0-100% |
| 现实改造落地数 | __件 | 今年已完成的实际改变 |

