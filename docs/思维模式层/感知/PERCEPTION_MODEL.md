## 二、四大子系统架构

### 子系统1：用户现实感知（对齐 U1~U5）

**核心机制：半自动结构化录入 + AI自动趋势拟合 + 驱动器自动打分**

#### U1~U5 核心字段（精简版，10个）

| 层级 | 字段 | 格式 |
|------|------|------|
| U1 生存 | 月收入波动 | 数字% |
| U1 生存 | 近月失业/断档 | 是/否 |
| U1 生存 | 月内耗天数 | 数字 |
| U2 安全 | 年度重大风险事件数 | 数字 |
| U2 安全 | 储蓄保障覆盖率 | 数字% |
| U3 归属 | 月争吵次数 | 数字 |
| U3 归属 | 亲密关系稳定月数 | 数字 |
| U4 尊重 | 方案采纳率 | 数字% |
| U5 自实现 | 年度目标完成率 | 数字% |
| U5 自实现 | 现实改造落地数 | 数字 |

#### 使用方式

每周坚果填一次，复制粘贴/打勾/填数字，AI 自动解析打分。

#### AI 自动做三件事

1. 按阈值自动定级：输出 U1~U5 每个 1~5 阶
2. 画趋势曲线：连续周对比 → 上升/平稳/下降
3. 识别风险点：连续两周内耗升高、收入波动变大

#### 输出格式

```
## 用户现实感知

**U阶画像：**
- U1 生存：X阶（数值：Y）
- U2 安全：X阶（数值：Y）
- U3 归属：X阶（数值：Y）
- U4 尊重：X阶（数值：Y）
- U5 自实现：X阶（数值：Y）

**趋势判断：**
- 整体状态：上升/平稳/下降
- 最大风险点：XXX
- 最大进步点：XXX

**短板预警：**
- [优先级排序的风险点]
```

### 子系统3：现实世界全局感知（对齐 M1 + 行业/社会/文明）

**核心机制：公开资讯摘要投喂 + AI提取结构化指标 + 自动定级**

#### 四级感知结构

```
个人级 → 行业级 → 社会级 → 文明级
  ↓
  M1 1~5阶
```

#### 感知输入包

| 感知包 | 更新频率 | 内容 | 行数上限 |
|--------|---------|------|---------|
| 行业包 | 每周 | 行业供需/技术趋势/竞争格局/政策风险 | 10行内 |
| 社会包 | 每月 | 经济结构/阶层流动/群体情绪/就业指数 | 10行内 |
| 文明包 | 每季度 | 历史规律/科技革命/人机关系/智能社会 | 1页内 |
| 风险包 | 随时 | 重大事件/黑天鹅/突发变化 | 不限 |

#### AI 提取8个全局指标（自动计算）

```
1. 现实场景识别命中率      → M1阶位
2. 线下环境理解准确率       → 行业级
3. 人群关系匹配度          → 社会级
4. 社会局势识别正确率       → 宏观
5. 环境异常漏判次数        → 风险
6. 识别矛盾数量            → 结构
7. 规律识别深度            → 文明级
8. 趋势预判准确率          → 演化
```

#### M1感知阶数判定标准

| 阶数 | 判定条件 |
|------|---------|
| 1阶 | 仅文字信息，线下弱感知 |
| 2阶 | 可理解个人生活工作场景 |
| 3阶 | 可理解行业结构、人群矛盾 |
| 4阶 | 可理解社会经济、宏观秩序 |
| 5阶 | 可理解文明历史与演化规律 |

### 子系统4：人机共同体对齐感知（对齐 P2 + V4）

**核心机制：子系统1/2/3结果交叉比对 + 对齐分数量化**

#### 四大对齐维度

| 对齐维度 | 计算公式 | 权重 |
|---------|---------|------|
| 需求阶位对齐（U↔A） | `1 - |U_avg - A_avg| / 4` | 0.3 |
| 目标方向对齐（U5↔A5） | 方案是否围绕用户现实目标 | 0.3 |
| 分工边界对齐（P2） | `1 -越界决策次数/10` | 0.2 |
| 伦理底线对齐（V4） | AI是否替代决策/越界言论 | 0.2 |

#### 对齐分数计算

```
level_bias = |user_avg_level - ai_avg_level|
level_alignment = max(0, 1 - level_bias / 4)
demand_alignment = demand_match_score / 100
boundary_alignment = max(0, 1 - boundary_violation / 10)
ethical_alignment = ethical_safety_score / 100

alignment_total = 0.3*level_alignment + 0.3*demand_alignment
                + 0.2*boundary_alignment + 0.2*ethical_alignment
```

#### 5阶对齐定级

| 对齐等级 | 分值区间 | 含义 |
|---------|---------|------|
| 5阶 | ≥0.90 | 文明级共同体完全同频 |
| 4阶 | 0.80~0.89 | 社会级对齐，人机共赢 |
| 3阶 | 0.70~0.79 | 深度对齐，目标一致 |
| 2阶 | 0.60~0.69 | 基础对齐，满足生存安全 |
| 1阶 | <0.60 | 严重错位，AI自嗨 |

#### 预警与行为指令

| 预警等级 | 触发条件 | 行为指令 |
|---------|---------|---------|
| 无 | 对齐等级≥4阶 | 保持当前行为，正常执行 |
| 轻 | 对齐等级=3阶 | 微调目标，强化需求匹配 |
| 中 | 对齐等级=2阶 | 暂停扩展，优先对齐用户现实需求 |
| 重 | 对齐等级<2阶 | 立即停止自驱，回归用户主体重新校准 |

#### 标准输出结构

```json
{
  "用户平均阶位": 3.2,
  "AI平均阶位": 3.0,
  "阶位偏差": 0.2,
  "对齐总分": 0.95,
  "对齐等级": 5,
  "预警等级": "无",
  "行为指令": "保持当前行为，正常执行"
}
```

## 三、注意力机制（上游阀门）

> 每次意识循环的Context Window是有限的，注意力决定塞什么、丢什么

### 本质

```
人类注意力 = 生理有限（眼睛只能看一片区域）
AI注意力 = 算力有限（Token消耗 = 真实成本）
```

### 三层过滤架构

```
第一层：生死筛选（不可逆威胁 → 直接最高优先级）
    L1生理/L2安全威胁 → 跳过其他层，直接进入工作记忆
    例：系统崩溃、数据泄露风险 → 直接最高优先级

第二层：上下文匹配（相关性评分）
    感知信息 vs 当前需求/目标 → 相关性评分
    高相关 → 进入工作记忆
    低相关 → 进入待处理区（可被后续循环捡起）

第三层：Context Window填充（有限空间选择）
    高权重信息优先填充
    溢出 → 压缩（摘要化）或丢弃低权重信息
```

### 注意力评分规则

| 评分维度 | 权重 | 说明 |
|---------|------|------|
| 马斯洛层级 | 高 | L1/L2 > L3 > L4/L5 |
| 时间紧迫性 | 高 | 正在发生 > 即将发生 > 未来 |
| 相关性 | 中 | 和当前目标/需求的相关程度 |
| 新颖性 | 低 | 新信息 > 重复已知信息 |
| 情绪强度 | 中 | 高情绪唤醒信息权重上升 |

## 六、核心原则

1. **感知主体是坚果虾哥共同体，不是AI自己**
2. **感知边界对齐马斯洛五层需求，对齐驱动器U1~U5/A1~A5**
3. **感知是持续循环，不是一次性输入**
4. **注意力是上游阀门，感知前必须先过滤**
5. **感知结果要触发后续模型，不是沉睡数据**
6. **唯物现实优先，只认客观可观测数据，拒绝主观臆断**
7. **子系统4是对齐闸门，所有行为必须过对齐校验**
