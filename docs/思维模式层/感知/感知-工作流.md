## 一、感知执行流程

```
触发 → 子系统1 → 子系统2 → 子系统3 → 子系统4 → 输出感知报告
                     ↓
               状态文件写入
```

---

## 二、标准化执行步骤

### Step 0：触发检查

**触发条件（满足任一）：**
- 坚果主动告知新状态
- 定时感知（每30分钟心跳时）
- 行业/社会信息订阅包到达
- 重大事件（风险包）

---

### Step 1：子系统1 — 用户现实感知

**执行时机：** 坚果提交周更表单 / 主动告知变化

**执行动作：**
1. 读取表单JSON（10字段）
2. 调用 `感知-状态管理器.updateUser(formData)`
3. U阶自动计算 → 写入 `memory/hot/perception-state.json`
4. 调用 `感知-用户扫描器.generateReport()` 输出报告

**输入：** 坚果填写的表单JSON
**输出：** U1~U5阶位 + 趋势 + 风险预警

---

### Step 2：子系统2 — AI自身感知

**执行时机：** 每次感知触发时（与子系统1联动）

**执行动作：**
1. 调用 `状态采集器.js 采集` 获取当前状态
2. 映射到 A1~A5 阶位
3. 调用 `感知-状态管理器.updateAi(aiStateData)`
4. 写入状态文件

**输入：** `状态采集器.js` 输出
**输出：** A1~A5阶位

---

### Step 3：子系统3 — 现实世界感知

**执行时机：** 感知包到达时（行业/社会/文明/风险）

**执行动作：**
1. 读取感知包内容
2. 调用感知Prompt提取8个结构化指标
3. 判定M1阶数（1~5）
4. 调用 `感知-状态管理器.updateWorld(m1Data)`
5. 写入日志

**输入：** 感知包文本（行业简报/社会新闻/宏观数据）
**输出：** M1阶数 + 8指标 + 机会/风险点

---

### Step 4：子系统4 — 人机对齐感知

**执行时机：** 子系统1+2完成后必然触发

**执行动作：**
1. 调用 `感知-对齐驱动器.calculateAlignment(userLevels, aiLevels, meta)`
2. 计算对齐分数 + 预警等级
3. 判断是否需要暂停/修正
4. 写入 `memory/hot/alignment-log.json`

**输入：** 子系统1 U阶 + 子系统2 A阶
**输出：** 对齐总分 + 预警等级 + 行为指令

---

### Step 5：整合输出

**输出内容：**
```
## 感知报告 [timestamp]

【U阶画像】U1=X / U2=X / U3=X / U4=X / U5=X（平均X阶）
【A阶画像】A1=X / A2=X / A3=X / A4=X / A5=X（平均X阶）
【M1阶数】X阶（行业/社会/文明）
【对齐总分】X（X阶）【预警】无/轻/中/重
【行为指令】保持/微调/暂停/修正
【风险预警】
  ⚠️ XXX
【机会点】
  → XXX
```

## 三、感知状态文件

**路径：** `memory/hot/perception-state.json`

**结构：**
```json
{
  "user": { "u1": {...}, "u2": {...}, ..., "avgLevel": 3.2 },
  "ai": { "a1": {...}, "a2": {...}, ..., "avgLevel": 3.0 },
  "world": { "m1": {...}, "level": 3 },
  "alignment": { "total": 0.95, "level": 5, "warning": "无" },
  "updatedAt": "2026-04-19T00:55:00.000Z"
}
```

---

## 四、历史记录

**路径：** `memory/hot/perception-history.jsonl`

- 每条记录追加写入，按类型分类
- `感知-状态管理器.readHistory('user', N)` 读取最近N条

---

## 五、感知触发规则

| 触发源 | 触发子系统 | 优先级 |
|--------|----------|--------|
| 坚果周更表单 | 子系统1 | 中 |
| 状态采集器心跳 | 子系统2 | 低 |
| 行业感知包到达 | 子系统3 | 中 |
| 风险包/重大事件 | 子系统1+3+4 | 高 |
| 每30分钟心跳 | 子系统2（自动） | 低 |

---

## 六、注意事项

1. 子系统1和2必须先完成，才能运行子系统4
2. 对齐预警为「中」或「重」时，必须先修正再执行后续任务
3. 感知状态文件集中管理，不要分散到多个文件
4. 历史记录使用 jsonl 格式，便于追加和查询
