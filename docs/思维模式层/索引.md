## 六模型思维流程

```
感知 → 需求 → 承接 → 计划 → 执行 → 反馈
```

### Prompt模板

| 文件 | 阶段 | 核心功能 |
|------|------|---------|
| `prompts/感知-prompt.md` | 感知 | 输入过滤 + 注意力打标签 |
| `prompts/需求-prompt.md` | 需求 | 马斯洛匹配 + 目标分解 |
| `prompts/承接-prompt.md` | 承接 | 复杂度评估 + ROI + 能力Gap |
| `prompts/计划-prompt.md` | 计划 | WBS分解 + 里程碑 + 风险预案 |
| `prompts/执行-prompt.md` | 执行 | 任务派发 + 状态追踪 + 阶段小结 |
| `prompts/反馈-prompt.md` | 反馈 | 满足度评估 + 元认知 + 记忆沉淀 |

### 认知模型

- `docs/business/COGNITION_MODEL.md` — 知识管理体系

## 支撑模块

### 意识主体.js

纯状态控制器，不调用18789端口。

- 状态管理（循环ID、当前阶段、触发类型）
- Prompt渲染
- 权限控制

### 意识循环.js

状态机 + 断点恢复。

- 六阶段状态机
- 断点保存与恢复
- 循环日志

### Prompt渲染器.js

模板渲染 + 变量注入 + 权限控制。

### 记忆模块.js

三层记忆 + 遗忘机制。

- 热层：current.md / lessons.md
- 温层：YYYY-MM-DD.md
- 冷层：cold/archive.md
