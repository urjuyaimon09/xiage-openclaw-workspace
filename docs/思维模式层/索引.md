## 六模型思维流程

```
感知 → 需求 → 承接 → 计划 → 执行 → 反馈
```

### 规则文档

| 文件 | 阶段 | 核心功能 |
|------|------|---------|
| `6模型/感知.md` | 感知 | 输入过滤 + 注意力打标签 |
| `6模型/需求.md` | 需求 | 马斯洛匹配 + 目标分解 |
| `6模型/承接.md` | 承接 | 复杂度评估 + ROI + 能力Gap |
| `6模型/计划.md` | 计划 | WBS分解 + 里程碑 + 风险预案 |
| `6模型/执行.md` | 执行 | 任务派发 + 状态追踪 + 阶段小结 |
| `6模型/反馈.md` | 反馈 | 满足度评估 + 元认知 + 记忆沉淀 |

### 认知模型

- `认知模型.md` — 知识管理体系（查/沉淀接口）

## 支撑模块（scripts/）

| 文件 | 功能 |
|------|------|
| `意识主体.js` | 纯状态控制器，不调用18789端口 |
| `意识循环.js` | 状态机 + 断点恢复 |
| `Prompt渲染器.js` | 模板渲染 + 变量注入 + 权限控制 |
| `记忆模块.js` | 三层记忆 + 遗忘机制 |
