## 定位

**核心问题：单次意识活动如何运行**

单次 OpenClaw 输入输出就是一次完整的意识活动。

---

## 单次意识活动流程

```
外部刺激（用户消息/心跳/定时任务）
    ↓
【Loop1：整合推理】
    读取各层索引.md（压缩的决策线索）
    ↓
    生成"意识映像"（frameId + sceneSummary + worldImage + sceneFingerprint）
    ↓
    决定需要哪些详细文档（pendingDocIds）
    ↓
【Loop2：判断推理】
    按需加载详细文档原文
    ↓
    叠加自我主体（SOUL.md + USER.md）
    ↓
    规则/认知校验
    ↓
    推理收敛 → 意志输出
    ↓
【执行】
    调用工具或生成回复
    ↓
【归档】
    写回记忆层（memory/hot/current.md）
```

---

## 意识映像结构

```json
{
  "frameId": "2026-04-18-T13:00",
  "sceneSummary": "当前场景1-2句话概括",
  "worldImage": {
    "activeRules": ["激活的规则ID列表"],
    "relevantFacts": ["从记忆/认知中提取的客观事实"],
    "pendingDocIds": ["Loop2需要读取的文档ID"],
    "cognitiveRefs": ["关联的认知项ID"]
  },
  "sceneFingerprint": [21维0/1向量],
  "confidence": 0.85,
  "reasoningTrace": "可选推理追踪"
}
```

## 各层索引在Loop1的角色

| 层级 | 索引文件 | Loop1读取目的 |
