# 文档归档规则

> 所有文档必须在 docs/ 中分类归档，根目录仅保留 OpenClaw 运行时必须的文件。

---

## 四层分类

| 层 | 定位 | 包含内容 |
|----|------|---------|
| 心智层 | 驱动引擎 | 驱动器、状态采集、思维引擎、Cron |
| 思维模式层 | 思考流程 | 六模型Prompt、认知模型、支撑模块 |
| 规则层 | 沟通契约 | 规则索引（实体在根目录） |
| 项目层 | 任务追踪 | 项目任务文档 |

---

## 根目录文件索引

根目录的运行时文件在 docs/规则层/索引.md 中记录索引。

---

## 归档流程

### 新建文档

```
1. 判断属于哪一层
2. 放入 docs/<层名>/
3. 添加 frontmatter（见下方）
4. 坚果确认「同意变更并升级版本」
5. Git commit
```

### 文档命名

```
<层级>-<名称>.md
示例：
心智层-驱动器索引.md
思维模式层-感知规则.md
```

### Frontmatter 模板

```markdown
---
title: 文档标题
status: draft          # draft / active / archived / deprecated
category: 思维模式层   # 心智层 / 思维模式层 / 规则层 / 项目层
version: 1.0.0
created: 2026-04-17
updated: 2026-04-17
description: 简要说明
---
```

### 状态流转

```
draft → active → archived / deprecated
```

| 状态 | 含义 | 触发 |
|------|------|------|
| draft | 草稿中 | 新建文件 |
| active | 生效中 | 坚果确认 |
| archived | 已归档 | 新版本发布或60天无修改 |
| deprecated | 已废弃 | 明确废弃 |

---

## 自动归档规则

- 新版本发布时，旧版本自动归档到 archive/
- 60天无修改的文档自动归档
- 废弃文档直接归档到 archive/
