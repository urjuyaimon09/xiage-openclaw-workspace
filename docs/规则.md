## 归档流程

### 新建文档

```
1. 判断属于哪一层/哪类
2. 放入对应目录
3. 添加 frontmatter
4. 坚果确认「同意变更并升级版本」
5. Git commit
```

### Frontmatter 模板

```markdown
---
title: 文档标题
status: draft          # draft / active / archived / deprecated
category: 思维模式层   # 系统文档 / 规则文档 / 思维模式文档 / 项目文档
version: 1.0.0
created: 2026-04-17
updated: 2026-04-17
description: 简要说明
---
```

### 状态流转

```
draft → active → archived / deprecated
```

| 状态 | 含义 | 触发 |
|------|------|------|
| draft | 草稿中 | 新建文件 |
| active | 生效中 | 坚果确认 |
| archived | 已归档 | 新版本发布或60天无修改 |
| deprecated | 已废弃 | 明确废弃 |
