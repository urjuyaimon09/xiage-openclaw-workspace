## 核心协作规则

### 触发词

| 触发词 | 效果 |
|--------|------|
| 「同意变更并升级版本」 | 执行文档修改 + 存档 + 版本升级 |
| 「同意，生效」 | 执行代码修改 + git commit |
| 「感知触发需求」 | 启动感知模型 |
| 「需求承接」 | 启动需求承接 |
| 「立项执行」 | 启动执行 |
| 「查认知」 | 查询认知库 |
| 「更新认知」 | 沉淀新认知 |
| 「复盘」 | 更新教训记录 |

### 工具调用锁死

- **文档 write/edit**：需要「同意变更并升级版本」
- **代码 write/edit**：需要「同意，生效」
