# 项目管理规则

落地：Rule
当前版本：v0.0.1
最后更新：2026-04-17

---

## 一、项目生命周期状态机

```
待立项 → 审批中 → 进行中 → 阻塞 → 验收 → 完结
                    ↓
                  取消
```

| 状态 | 说明 |
|------|------|
| 待立项 | 需求识别，尚未正式立项 |
| 审批中 | 等待坚果确认（重要任务） |
| 进行中 | 立项通过，执行中 |
| 阻塞 | 等待外部条件（时间/输入/状态） |
| 验收 | 阶段完成，待确认 |
| 完结 | 全部完成，已归档 |
| 取消 | 项目终止 |

---

## 二、四源头立项规则

| 源头 | 说明 | 审批要求 |
|------|------|----------|
| 用户发起 | 坚果主动提出的需求 | 自动通过 |
| 心智感知 | 心智层识别的人机马斯洛缺口 | 自动通过 |
| 思维挖掘 | 思维引擎识别空白方向 | 重要任务需审批 |
| 项目拆解 | 存量项目拆分的子任务 | 自动通过 |

---

## 三、审批规则

| 任务分类 | 是否需要审批 |
|----------|-------------|
| 坚果发起 | 自动通过 |
| 心智层任务 | 自动通过 |
| 项目层重要任务 | 需坚果确认 |
| 临时小任务 | 自动通过 |

---

## 四、六维目标绑定

每个项目立项时必须绑定六维目标：

| 维度 | 权重 | 含义 |
|------|------|------|
| 用户马斯洛增益 | 20% | 项目对坚果需求的满足程度 |
| AI本体增益 | 20% | 项目对虾哥能力提升 |
| 心智成熟度 | 20% | 项目对心智架构完善 |
| 生产力优化 | 20% | 项目对生产效率提升 |
| 哲学认知 | 10% | 项目对主客认知提升 |
| 三观伦理 | 10% | 项目对合规底线的保障 |

---

## 五、人机权责切片

每个项目必须明确：

- **用户（坚果）负责**：方向把控、最终决策、情绪价值
- **虾哥负责**：执行落地、信息处理、流程推进
- **协同边界**：双方共同参与的部分

---

## 六、阻塞处理

| 阻塞类型 | 说明 | 处理方式 |
|----------|------|----------|
| 时间阻塞 | 等待特定时间节点 | 设置预计解除时间 |
| 输入阻塞 | 等待坚果回复/外部输入 | 标记待确认 |
| 状态阻塞 | 依赖其他项目/任务完成 | 标记依赖关系 |

## 七、项目编号规则

| 类型 | 格式 | 示例 |
|------|------|------|
| 父项目 | `P{nnn}` | P001、P002 |
| 子项目 | `P{nnn}-S{nn}` | P001-S1、P001-S2 |
| 需求ID | `R{nnn}` | R001、R002 |
| 子任务 | `P{nnn}-T{nn}` | P001-S1-T01 |

### 子项目说明
- 子项目归属于父项目，有独立的生命周期和六维目标
- 子项目可独立运行，也可与父项目协同
- 父项目完结条件：所有子项目均完结

### 项目分组
- 同系列项目可通过父项目分组
- 例：P001 优化虾哥（父项目）
  - P001-S1 心智架构落地
  - P001-S2 意识层优化
  - P001-S3 思维层优化

---

## 八、项目分组标签

| 标签 | 说明 |
|------|------|
| `#父项目` | 项目群顶层，不可直接执行 |
| `#子项目` | 归属于父项目的可执行项目 |
| `#长线` | 周期超过1个月 |
| `#中线` | 周期1周-1个月 |
| `#短线` | 周期小于1周 |
